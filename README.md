# Anime Requester

Site web statique pour rechercher des animes via l'API Anime DB de RapidAPI. Projet réalisé en binôme avec [Adrien Barbet](https://github.com/Nutella9775).

## Fonctionnalités

- Recherche d'un anime par nom, par identifiant ou par classement
- Filtrage par genres (liste chargée depuis l'API)
- Affichage responsive des résultats

## Stack

HTML, CSS, JavaScript (Fetch API), sans framework.

## Utilisation

1. Créer une clé gratuite sur RapidAPI et s'abonner à l'API Anime DB.
2. Ouvrir `index.html` dans un navigateur.
3. Saisir la clé quand le site la demande. Elle est stockée uniquement dans le `sessionStorage` du navigateur, jamais dans le code.
